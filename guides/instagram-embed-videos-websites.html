Embedding Instagram Videos on Your Website: The Official Method

Add Instagram posts and Reels to your website with the official embed code, and keep them working.

Embedding is the legitimate way to show an Instagram post on your website. Instead of copying the video file, you add a small piece of code that loads the post from Instagram, with the creator's name, caption, and a link back to the original. This guide explains how embedding works, how to add an embed to a page, and what to do when an embed stops working.

How embedding works

Instagram provides an embed code for every public post. The code is an HTML blockquote with the post's link, plus a script that turns it into a formatted preview. When a visitor opens your page, their browser loads the post from Instagram, so the view counts for the creator and the content is always current. You do not host the video or the image, which is why embedding is generally lawful, in the same way that linking to a page is lawful.

Add an embed to your page

Open the post on instagram.com in a browser, click the three-dot menu, and choose Embed. Copy the code it gives you and paste it into your page's HTML where you want the post to appear. The embed includes the script tag only once per page, even if you embed several posts, so keep the script and repeat only the blockquote for each additional post. Test the page after you add the embed, and check it on a phone, because embeds are responsive and should resize to the screen.

When embeds break

An embed stops working if the post is deleted, if the account goes private, or if Instagram changes its embed system. If an embed shows a blank space, open the original link to check whether the post still exists. If it does, the problem may be a script blocker or an ad blocker in your browser, so test in a private window. If the post is gone, remove the embed and replace it with a link or a different post, rather than leaving a broken space on your page.

Embedding vs downloading

Embedding and downloading solve different problems. Embedding is for showing a post on your site while keeping the credit and the link to the creator. Downloading is for keeping a personal copy, and it requires permission for anything beyond your own content. For a website, embedding is almost always the better choice: it is lawful, it credits the creator, it stays current, and it does not use your storage. If you run a blog, embed the posts you want to feature and link to the creators, and your readers will thank you for it.

Embeds and page speed

Every embed on a page adds weight, because the visitor's browser must load code from Instagram as well as your own page. One or two embeds are fine, but a page with ten embeds will load slowly, especially on a phone, and slow pages lose visitors and rank lower in search results. The practical limit is three or four embeds per page, and if you need more, link to the extra posts instead of embedding them. You can also delay loading embeds until the visitor scrolls near them, which keeps the first view of the page fast. Test your page speed after adding embeds, using a free tool that measures loading time on a mobile connection, and remove any embed that is not earning its place. A fast page with two good embeds beats a slow page with ten, every time.

Frequently Asked Questions

How do I embed an Instagram post?

Open the post in a browser, click the three dots, choose Embed, and copy the code into your page.

Do embeds need an Instagram account?

No. Visitors can see an embedded public post without logging in, in most cases.

Why did my embed stop working?

The post may have been deleted or the account may have gone private. Check the original link.
